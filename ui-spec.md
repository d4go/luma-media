# Luma Media UI Specification

Frontend:

-   Vue3
-   TypeScript
-   Naive UI

## Dashboard

Display:

-   media count
-   task count
-   success count
-   failed count
-   recent activity

## Folder Management

Functions:

-   add folder
-   edit folder
-   delete folder
-   scan now

## Task Center

Functions:

-   list tasks
-   retry
-   cancel
-   detail

## Media Library

Display:

-   filename
-   metadata status
-   provider id
-   last scrape time

## Settings

Configuration:

-   MetaTube URL
-   output format
-   scan interval
-   overwrite strategy
-   log level

UI principles:

-   minimal
-   desktop first
-   clear information hierarchy
